## Quick start

1. Open any tool above.
2. Drop your input (file or text).
3. Adjust presets, export locally. Done — nothing stored.

## Why client-side

- **Privacy**: inputs are processed in the tab, not on a server.
- **Speed**: no round-trip, instant re-render.
- **Free forever**: no per-user server cost, so no paywall.
